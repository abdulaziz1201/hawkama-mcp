# MCP حوكمة الجمعيات الأهلية

خادم MCP يقرأ ملفات مجلد عام في Google Drive (PDF و Word و Google Docs)، ويعطي Claude ثلاث أدوات:

| الأداة | وش تسوي |
|---|---|
| `list_documents` | تعرض كل الوثائق وتصنيفها |
| `search_documents` | تبحث داخل نصوص الوثائق وترجع المقطع ورقم الصفحة والرابط |
| `read_document` | تقرأ وثيقة كاملة أو صفحات محددة منها |

## التشغيل على Render
1. ارفع الملفات الأربعة (`server.py`, `requirements.txt`, `render.yaml`, `README.md`) على مستودع في GitHub.
2. في render.com: **New ← Blueprint** واختر المستودع (يقرأ `render.yaml` تلقائياً).
3. بعد النشر افتح رابط الخدمة، ولازم يطلع `"ready": true`.
4. رابط الـ MCP = رابط الخدمة + `/mcp`

## تغيير المجلد (مثلاً لمجلد الأوقاف)
غيّر قيمة `FOLDER_ID` في إعدادات Render (Environment)، وغيّر `SERVER_NAME` إذا تبي اسم مختلف. ما تحتاج تعدّل الكود.

## ملاحظات
- المجلد لازم يكون: أي شخص لديه الرابط ← عارض.
- الملفات الجديدة تظهر تلقائياً كل 6 ساعات (`REFRESH_HOURS`)، أو فوراً بعد إعادة تشغيل الخدمة.
- ملفات PDF المصوّرة (سكانر) ما تنقرأ.
